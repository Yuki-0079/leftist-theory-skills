# 倦怠社会

> 韩炳哲的社会病理学诊断——从规训社会到功绩社会，从免疫学到肯定性暴力

## 概述

本 skill 基于韩炳哲《倦怠社会》（Müdigkeitsgesellschaft）的结构化知识库，覆盖全书的核心理论命题：范式转移（免疫学→肯定性社会）、功绩社会与自我剥削、深度无聊与创造力、根本性倦怠的共同体维度、神圣时间与节日等。

## 核心概念体系

### 诊断层

| 概念 | 难度 | 关键要点 |
|:-----|:----:|:---------|
| 范式转移 | ★★★ | 从否定性（免疫学）到肯定性（功绩社会）的根本转变 |
| 肯定性暴力 | ★★★ | 来自过量的同类而非他者的暴力——饱和而非排斥 |
| 功绩社会 | ★★★ | 「能够」取代「应当」，自我剥削取代外在规训 |
| 自我剥削 | ★★☆ | 在自由感中进行的自我压榨——比外在剥削更高效 |
| 神经暴力 | ★★★ | 源自系统内部的梗阻式暴力，免疫反应对它无效 |

### 创造性批判层

| 概念 | 难度 | 关键要点 |
|:-----|:----:|:---------|
| 深度无聊 | ★★☆ | 创造性的精神条件——本雅明的「孵化的梦鸟」 |
| 超注意力 | ★★☆ | 碎片化的注意力——多工作业是倒退而非进步 |
| 消极的能力 | ★★★ | 不去做某事的能力——作为积极社会的解毒剂 |
| 沉思生活 | ★☆☆ | 被积极社会遗忘的生命形式——超越忙碌的在场 |

### 替代性愿景层

| 概念 | 难度 | 关键要点 |
|:-----|:----:|:---------|

| 根本性倦怠 | ★★★ | 开启中间地带——自我弱化，世界延展 |
| 神圣时间 | ★★☆ | 节日而非劳作——逗留而非消逝——庆典而非生产 |
