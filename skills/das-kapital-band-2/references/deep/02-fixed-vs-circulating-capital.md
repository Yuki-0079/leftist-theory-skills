# 固定资本与流动资本的区分 — 深度分析

> 对应条目：dk2-006, dk2-041 ~ dk2-044 | 来源：第二篇 第8~11章

## 定义

固定资本和流动资本是按预付资本价值向产品转移的不同方式对生产资本的划分。固定资本（如厂房、机器）的价值是逐步转移到产品中的，在实物形式上继续多次使用期间发挥作用；流动资本（如原材料、辅助材料、劳动力）的价值是一次性或在一个周转期内全部转移到产品中，必须由产品出售全部补偿。区分的关键标准不是物的物理属性（是否固定、是否移动），而是**价值转移方式**。投在劳动力上的资本虽然购买的不是物，但在周转方式上属于流动资本——因为它的价值全部加入产品且必须全部由产品价值补偿。

## 判定标准

| 标准 | 说明 |
|------|------|
| 价值是否在多次生产周期中逐渐转移 | 是→固定资本；否→流动资本 |
| 实物形式是否在多次生产中保持不变 | 是→固定资本；否→流动资本 |
| 是否需要在每个周转期内全部更新 | 是→流动资本；否→固定资本 |
| 区分标准是价值周转方式而非物理属性 | 这是马克思与斯密的根本分歧点 |

## 固定/流动资本 vs 不变/可变资本的对比

| 维度 | 固定/流动资本区分 | 不变/可变资本区分 |
|:-----|:-----------------|:-----------------|
| 划分依据 | 价值转移方式（周转方式） | 剩余价值来源 |
| 划分范围 | 生产资本内部（不包括商品资本和货币资本） | 全部资本 |
| 目的 | 考察周转速度和资本效率 | 考察剩余价值的来源 |
| 劳动对象（原料） | 流动资本 | 不变资本 |
| 劳动力 | 流动性 | 可变资本 |
| 机器设备 | 固定资本 | 不变资本 |
| 混淆的后果 | 斯密将流动资本与流通资本混同 | — |

## 马克思对斯密的批判

亚当·斯密犯了两个根本混淆：
1. 把与固定资本相对立的流动资本同属于流通领域的资本形式（商品资本和货币资本，即流通资本）混为一谈
2. 以生产资本要素是否"更换所有者或进一步流通"作为区分标准，而不是以价值转移方式为标准

斯密认为固定资本"不更换所有者"就能提供利润，但马克思指出生产资本的一切要素都同样固定在生产过程中。资本成为固定资本，不是因为固定在劳动资料中，而是因为投在劳动资料上的价值的一部分仍然固定在劳动资料中，另一部分作为产品价值流通。魁奈从再生产过程的必然性引出区别，比斯密更为正确。

## 常见错误

| 错误 | 正确理解 |
|------|---------|
| 认为固定资本=不动的东西（如建筑物） | 船舶和机车是典型的固定资本，但它们处于运动之中；煤炭在炉中完全耗尽，虽是"固定的"但属于流动资本 |
| 混淆固定/流动资本与不变/可变资本 | 固定资本包含机器（不变资本）但不包含原料（也是不变资本但不是固定资本）。两对概念交叉但不重合 |
| 认为劳动力是流动资本 | 劳动力本身不是资本，预付在劳动力上的资本在周转方式上属于流动资本 |

## 创作应用

| 应用场景 | 操作方式 |
|---------|---------|
| 产业分析 | 固定/流动比例决定了一个行业的资金需求和周转特征——钢铁业（高固定）vs 餐饮业（高流动） |
| 企业财务叙事 | 固定资本维护费用与修理费用之间的灰色地带可以设计财务造假情节 |
| 科幻经济设定 | AI和自动化使固定资本比例升高、流动资本中劳动力部分下降——影响整个经济结构 |
