# 幽灵般的商品: 马克思的拜物教批判的解构重读

## 概述

德里达在第五章"隐形者的显形"中对马克思《资本论》中的商品拜物教理论进行了最具原创性的解构重读。他聚焦于马克思著名的"木桌"比喻——一张普通的木桌一旦成为商品，就"从它的木脑袋里生出比它自动跳舞还奇怪得多的狂想"——论证商品形式本身具有一种不可还原的幽灵性（spectrality）。

## 木桌的舞蹈: 拜物教的核心比喻

马克思在《资本论》第一卷中写道：
> "用木头做桌子，木头的形状就改变了。可是桌子还是木头，还是一个普通的可以感觉的物。但是桌子一旦作为商品出现，就转化为一个可感觉而又超感觉的物了。"

德里达对这一比喻进行了逐词分析：
- 木材: 可感觉的物质（感性的）
- 商品: 可感觉而又超感觉的东西（感性的非感性之物）
- 舞蹈: 木桌"用它的脚站在地上"并"用头倒立"
- 木脑袋: 商品像人一样思考（拟人化）
- 狂想: 从桌子中生出比自动跳舞更奇怪的幻想

德里达认为，这个比喻不仅是一种修辞手段，更是一种理论性的展示——商品的神秘特征只有通过幽灵的比喻才能被充分理解。

## 幽灵般的对象性 (Gespenstige Gegenständlichkeit)

马克思在《资本论》中使用的"幽灵般的对象性"（gespenstige Gegenständlichkeit）是德里达分析的重点：
- 劳动产品成为商品后，"剩下的只是同一的幽灵般的对象性"
- 这是"无差别的人类劳动的单纯凝结"
- 它既不是物理的实体，也不是纯粹的幻想——而是一种"可感觉的超感觉物"

德里达进一步指出，这种幽灵般的对象性具有以下特征：

1. **非实体性**：不是物理意义上的物
2. **社会性**：是人与人之间社会关系的物化形式
3. **拟人性**：商品被赋予了人的语言和意志
4. **自主性**：商品似乎获得了独立于它的生产者的生命

## 马克思与施蒂纳: 谁是真正的幽灵学家?

德里达通过马克思与施蒂纳的论战揭示了马克思自身分析中的张力：
- **施蒂纳**（在《唯一者及其所有物》中）：批判一切普遍概念——国家、民族、人类、上帝——都是压制个体的"幽灵"或"怪影"
- **马克思**（在《德意志意识形态》中）：批判施蒂纳的批判本身也是一种唯心主义的"幽灵"操作

德里达指出一个反讽：马克思在用幽灵的比喻批评施蒂纳时，自己也在使用同样的比喻。马克思和施蒂纳都在"搜捕幽灵"，但方法不同。施蒂纳试图通过将一切都归结为"唯一者"来驱散幽灵，马克思则试图通过揭示幽灵的物质基础来驱散它。两者都未能完全摆脱幽灵——因为任何批判都已经预设了它所批判的对象。

## 使用价值的"纯粹性"问题

德里达对马克思最具挑战性的质疑指向使用价值的地位：

**马克思的立场**：使用价值是"纯粹的"——它可以与交换价值分开考虑；商品的神秘性始于交换价值

**德里达的反驳**：
- 不存在纯粹的使用价值——任何物只要被认定为"可用"，就已经被置于重复、比较、交换的可能性之中
- 使用价值的概念限制本身可能是一种"理论花招"——马克思为了给批判确立一个坚实起点而设定的虚构
- 如果使用价值本身就已经被交换的可能性所"污染"，那么幽灵性比马克思所承认的更为根本

这一论证指向了一个更激进的结论：商品拜物教不是资本主义特有的现象，而是任何社会形式中都会存在的结构——只要有交换、有重复、有"物"被纳入社会关系。

## "现象学的花招"

德里达在第五章的子标题"现象学的花招"中揭示了马克思方法的另一个层面：
- 马克思要求读者"一眼就看到难以看见的东西"
- 但这种"一眼看到"本身就是一个花招——它预设了一种纯粹的现象学洞识
- 马克思的现象学洞识在分析使用价值时是有效的（"一眼就看到这是木头做的桌子"），但到了分析交换价值时就不够了——交换价值恰恰是"看不见的"

德里达并不认为这个"花招"是马克思的错误，而是将其视为批判活动的必然特征：任何批判都需要一个起点，但这个起点本身总是可疑的。马克思的批判既是强有力的（它揭露了商品形式的秘密），又是受到限制的（它的起点——纯粹的使用价值——本身并不纯粹）。
