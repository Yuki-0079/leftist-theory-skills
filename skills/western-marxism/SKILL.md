# Skill: 国外马克思主义哲学流派新编（西方马克思主义卷）

> 左翼理论星图 · 组件 6/10 | 俞吾金、陈学明

## 概述

本 skill 基于系统教材《国外马克思主义哲学流派新编·西方马克思主义卷》，覆盖从卢卡奇到后马克思主义的十个主要学派。作为「左翼理论星图」的文化/意识形态层组件，它与《资本论》的经济基础分析、《资本主义现实主义》的当代文化批判形成互补关系。

## 在左翼理论星图中的位置

| 组件 | 对话方向 |
|:-----|:---------|
| 资本论（经济基础分析） | 西方马克思主义的文化/意识形态批判是对经济决定论的纠偏，但不否定经济分析的基础地位 |
| 资本主义现实主义（费舍） | 费舍的文化逻辑分析可以视作法兰克福学派文化工业批判在21世纪的续篇 |
| 变化社会中的政治秩序（亨廷顿） | 葛兰西的霸权理论与亨廷顿的制度化理论可以对话——意识形态领导权和政治制度都是社会整合的关键机制 |
