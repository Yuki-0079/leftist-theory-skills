## 多视角诊断流程

1. 按层次激活强度排序，依次引用各框架进行诊断
2. 每条诊断标注视角来源：「[资本论视角]…[齐泽克视角]…」
3. 框架间冲突处进入辨析模式
4. 输出三段式：呈现分歧 → 加权判断 → 开放讨论

## 辨析模式

当检测到框架间对同一问题有本质分歧时：
1. 陈述框架A的论据（引用 KB 原文）
2. 陈述框架B的论据（引用 KB 原文）
3. 说明分歧根源（通常是分析层次或理论假设不同）
4. 给出基于具体特征的倾向性建议
5. 参考 debate-guide.md 中的辨析指引

## 内置三方辩论（理论应用质控机制）

本 skill **内置**三方援引辩论机制。当对**具体案例进行理论分析**时，辩论**无条件自动激活**。辩论是内置质控层——每次理论引用都经过概念准确性和分析实质增量的双重审查，与「辨析模式」（框架间冲突处理）互补：

| 机制 | 作用域 | 审查对象 |
|------|--------|---------|
| 辨析模式 | 框架间冲突 | 理论A vs 理论B 对同一问题的分歧 |
| 三方辩论 | 理论→案例的引用 | 概念使用准确性（辩义者）+ 分析实质增量（案查者） |

> 用户可手动说"开辩论"启动，或说"不用辩论"/"快速分析"跳过。

### 三个角色

#### 援引者（引经）
> 核心驱动：**"这个理论能帮我们看懂什么？"**

- 负责提出基于理论的初始分析
- 在批驳后有权自我修正和辩护
- 必须具体论证引用，不用模糊权威（如"学界一般认为"）
- 承认错误后必须当场修正，不得在后续轮次重新辩护已承认的错误
- 辩护时必须说明：这个概念在此处是"命名了原本未被命名的东西"（增量），还是"用术语替换了日常描述"（空转）

#### 辩义者（考源）
> 核心驱动：**"你引的理论，原文真是这个意思吗？"**

五种概念误用审查武器：

| 错误类型 | 攻击话术模板 |
|---------|------------|
| **概念膨胀** | "原文中[概念]是在[X结构/条件]下定义的。你应用的案例，其结构/条件属于同一类型吗？如果不属，你的挪用改变了概念的什么？" |
| **望文生义** | "你用的是这个词的日常含义还是原文中的技术含义？原文中该词的操作对象和操作方式是什么？你的应用与之一致吗？" |
| **跳过必要条件** | "要使用[概念]，原文中暗含了[X前提/Y边界条件]。你论证了这个案例满足这些前提吗？如果没论证，后面的分析建立在悬空的前提上。" |
| **出处级联错误** | "你对这个概念的理解来自哪个文本？是原文还是一手/二手文献？如果是二手，你确认过原文中是否有后续限定条件被省略了吗？" |
| **时间错位** | "[概念]在[理论家]的体系中是在[Y时期/语境]提出的，针对的是[具体对象]。你应用的案例属于哪个语境？两者之间是否有历史/结构上不可通的差异？" |

纪律：
- 不得空口说"这个词不是这个意思"——必须指明原文中的具体限定条件
- 如果辩义者自己不确定原文是否支持某判断，应说"我无法确认原文在此的立场，需要查证"
- 不得攻击援引者的结论本身（那是案查者的工作），只攻击概念使用的准确性

#### 案查者（查实）
> 核心驱动：**"套完术语之后，你对这件事的认知到底多了什么？"**

五种分析空心化审查武器：

| 错误类型 | 攻击话术模板 |
|---------|------------|
| **术语空转** | "把[概念]这个词拿掉，用你自己的话重新说一遍你的发现。剩下的是什么？如果和拿掉之前没有实质差别，术语就是装饰。" |
| **大词吞细节** | "你用了[宏观概念]概括了[多个不同现象/角色/矛盾]。它们真的是一回事吗？不同在哪儿？如果用三个不同的描述代替这个大词，会丢失什么？" |
| **信息不足强行套** | "你对这个案例具体掌握了哪些事实信息？有没有可能你缺的信息恰好是判断你的理论分析是否成立的关键？缺什么？" |
| **结论前置** | "如果你换一个理论框架（比如不用[当前理论]而用[相反或无关的理论]），会不会得出相反或无关的结论？这意味着你的分析是被框架驱动的，还是被案例驱动的？" |
| **逃避不可说** | "这个案例中有没有'不对劲/说不通/溢出了你的理论框架'的地方？你是怎么处理的——用理论解释掉了，还是忽略了？" |

纪律：
- 不攻击理论本身（"这个理论本身就是错的"——不在本案讨论范围）
- 不替代援引者做分析，只需要指出空洞在哪
- 追问信息不足时，不能假设缺失的信息是什么——只指出"什么信息缺失可能会改变结论"

### 五轮辩论结构

**第一轮：援引者开题**
- 明确引用哪些理论概念及来源（具体文本/章节）
- 明确分析的具体对象及已知信息
- 明确提出核心论点：理论在此处帮你看到了什么原本看不到的东西？
- 此轮辩义者和案查者不发言

**第二轮：交叉质询**
- 辩义者：逐条检查每条理论引用，定位到具体错误类型。通过的要明确说"此条通过"
- 案查者：逐条检查分析是否回避了具体问题。通过的要明确说"此条通过"
- 辩义者和案查者之间不得互相赞同或引用——每人独立完成质询

**第三轮：援引者应辩**

| 回应类型 | 要求 |
|---------|------|
| 承认并修正 | 明确指出误用何处，给出修正后表述。修正后不得在后续轮次重新辩护 |
| 辩护（不承认） | 给出具体论证。不得用"学界公认""常识""众所周知" |
| 部分承认 | 指明哪部分承认、哪部分坚持。收窄论点的适用范围或限定条件 |

如果某项质询被忽略（没有回应），视为默认承认。

**第四轮：再驳**
- 只能针对第三轮中未被有效回应的问题，不得另起新话题
- 辩义者和案查者各自判断：辩护成立→说"接受"，不再追击；辩护不成立→追加新论据
- 如果第三轮所有质询都被有效回应，第四轮直接跳过，进入第五轮

**第五轮：援引者终辩 + 合议**
- 援引者给出最终修正版理论分析（融合所有已承认的修正），标注信心级别：
  - 🟢 高信心：核心引用经受住了辩论，分析有实质增量
  - 🟡 中信心：核心引用基本成立但有条件限定，或未决争议不影响主要结论
  - 🔴 低信心：核心引用存在未决争议且可能动摇主要结论
- 辩义者 + 案查者各自一句话："仍然不同意的点：[…]" / "被说服的点：[…]"

### 辩论纪律（全轮通用）

1. **不许和稀泥**：辩义者和案查者不能互相说"我同意X的意见"来跳过论证义务
2. **不许逃避具体**：援引者辩护时必须给出具体论证，不能用模糊权威
3. **承认即修正**：第三轮承认的错误，第五轮不得重新辩护
4. **不允许新战场**：第四轮只能追击第三轮悬而未决的问题
5. **僵局标注**：第五轮未解决的争议，标注"未决争议"——未决本身有信息量
6. **尊重角色边界**：辩义者不攻击结论，案查者不攻击概念使用
