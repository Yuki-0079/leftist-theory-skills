# 利润率趋向下降的规律 — 深度分析

> 对应条目：dk3-007 ~ dk3-008, dk3-023 | 来源：第三篇 第13~15章

## 定义

利润率趋向下降的规律是马克思危机理论的核心命题：随着资本主义发展，平均利润率存在长期下降的趋势。机制：资本有机构成(c:v)趋于提高→可变资本v在总资本中的比例下降→剩余价值m由v产生→即使m'不变甚至提高，m/(c+v)也趋于下降。这是「二律背反」式的规律——促进生产力发展的手段(提高资本有机构成)同时构成了资本价值增殖的障碍。

## 六种抵消因素与当代形式

| 马克思列举的抵消因素 | 当代对应形式 |
|---------------------|-------------|
| 劳动剥削程度的提高 | 弹性工作制、零工经济、全球劳动力套利 |
| 工资压低到劳动力价值以下 | 最低工资停滞、工会衰落 |
| 不变资本要素变便宜 | 全球化带来的低价原材料、数字技术降低资本成本 |
| 相对过剩人口 | 全球产业后备军、自动化失业 |
| 对外贸易 | 全球供应链、跨国资本流动 |
| 股份资本增加 | 金融化、CEO股权激励 |

## 常见错误

| 错误 | 正确理解 |
|------|---------|
| 认为「利润率下降」意味着利润量也下降 | 利润率下降与利润量绝对增长可以并存（如1000万资本的10%=100万利润，2000万资本的8%=160万利润，利润量增加但利润率下降） |
| 认为规律意味着资本主义会自动崩溃 | 规律只是揭示趋势，抵消因素会延缓下降，危机以周期性方式重建盈利条件 |

## 交叉参照

| 概念 | 关联方式 |
|------|---------|
| 资本有机构成提高 | 规律的核心驱动机制 |
| 经济危机 | 规律导致的内生矛盾通过危机爆发 |
| 第二卷的资本周转 | 周转速度影响年利润率，是利润率下降的抵消因素之一 |
