# Skill: 资本论第三卷 · 资本主义生产的总过程

> 左翼理论星图 · 组件 3/8+ | 基于卡尔·马克思《资本论》第三卷（人民出版社纪念版），恩格斯1894年编辑

## 概述

本 skill 是 **「左翼理论星图」** 项目的组成部分，基于马克思《资本论》第三卷《资本主义生产的总过程》的结构化知识库。第三卷是《资本论》理论部分的终结，引入了竞争、平均利润、生产价格、信用、地租等具体形式，完成了从抽象到具体的全部理论行程。与前两卷相比，第三卷更接近资本主义的表面现象，更适合直接用于对现实或虚构资本主义社会的经济分析。

## 核心概念体系

### 利润与平均利润（第一~二篇）

| 概念 | 难度 | 关键要点 |
|:-----|:----:|:---------|
| 成本价格k=c+v | ★★☆ | 资本家视角的商品费用，掩盖不变/可变资本的区别 |
| 利润率p'=m/(c+v) | ★★☆ | 剩余价值与总资本的比率，掩盖剥削 |
| 资本有机构成与利润率差异 | ★★★ | 有机构成越高的部门，利润率越低 |
| 平均利润与生产价格 | ★★★★★ | 竞争使利润平均化，生产价格=成本+平均利润 |
| 市场价值与市场生产价格 | ★★★★ | 部门内部竞争vs部门间竞争的不同结果 |

### 利润率下降与危机（第三篇）

| 概念 | 难度 | 关键要点 |
|:-----|:----:|:---------|
| 利润率趋向下降的规律 | ★★★★★ | 有机构成提高导致利润率趋势性下降 |
| 六种抵消因素 | ★★★★ | 剥削加深、工资压低、外贸等延缓下降 |
| 规律的内部矛盾 | ★★★★★ | 生产力发展与价值增殖的根本冲突 |

### 资本的具体形式（第四~五篇）

| 概念 | 难度 | 关键要点 |
|:-----|:----:|:---------|
| 商人资本（商品经营资本） | ★★★ | 流通资本的独立化，参与剩余价值分配 |
| 商业利润 | ★★★ | 购销差价是剩余价值的扣除 |
| 生息资本 G-G' | ★★★ | 所有权与使用权分离，资本拜物教的最高形式 |
| 利息与企业主收入 | ★★★ | 利润分割掩盖了剥削关系 |
| 虚拟资本 | ★★★ | 有价证券的价值与实际资本分离 |
| 信用制度 | ★★★ | 促进平均化和集中，同时加剧危机 |
