# Skill: zizek-looking-awry

> 齐泽克通俗文化分析方法论的结构化知识库

## 概述

本 skill 基于斯拉沃热·齐泽克《斜目而视：透过通俗文化看拉康》，提供拉康式文化批评的系统知识和可迁移的分析范式。

### 核心定位

| 维度 | 说明 |
|:-----|:------|
| **领域** | `cultural_theory` |
| **方法论** | 斜目而视法——通过文化文本的形式结构展示理论概念 |
| **分析粒度** | 形式特征 -> 力比多逻辑 -> 理论结构 |
| **理论刚性** | 描述性（非规定性） |
| **通用性** | 广泛（特别适用于文学/电影/文化分析） |

| 指标 | 数值 |

## 使用指南

### 适用场景

| 场景 | 说明 |
|:-----|:------|
| 电影分析 | 使用斑点分析+三阶段范式进行电影形式分析 |
| 文学批评 | 使用时间扭曲+共谋错误范式进行叙事分析 |
| 文化批判 | 使用意识形态感官快感+淫秽补充范式 |
| 政治分析 | 使用大对体的无知法则+形式民主批判 |
| 教学演示 | 使用斜目而视法将抽象理论转化为可视化的形式分析 |

### 分析流程

```
1. 选择分析对象 → 确定适用的分析范式
2. 剥离叙事内容 → 提取纯形式结构
3. 识别斑点/例外 → 哪个元素"不应该在那里"？
4. 追溯力比多逻辑 → 这个形式揭示了什么欲望结构？
5. 连接理论概念 → 形式结构与哪个概念共振？
6. 综合 → 撰写分析报告
```

### 阅读路径

```
新手路径：    斜目而视法 → 活死人的回归 → 大对体的无知法则
进阶路径：    口唇/肛门/阳物 → 希区柯克式斑点 → 凝视与声音
应用路径：    选择分析目标 → 选择范式 → 按分析流程操作
```
