# Skill: 德意志意识形态

## 概述

基于马克思和恩格斯《德意志意识形态》（1845-1846）的系统化知识库。覆盖历史唯物主义基本原理、意识形态批判、费尔巴哈批判、分工与私有制、共产主义理论、真正的社会主义批判等核心主题。适合对马克思主义哲学、历史唯物主义、意识形态理论进行理论分析和文化批判。

## 触发场景

- 用户提到"德意志意识形态"、"历史唯物主义"、"意识形态批判"、"马克思主义哲学"
- 用户讨论"生产力与生产关系"、"经济基础与上层建筑"、"社会存在决定社会意识"
- 用户涉及"分工与私有制"、"异化"、"共产主义"、"市民社会"
- 用户使用"统治阶级的思想"、"占统治地位的思想"等概念
- 用户请求分析费尔巴哈、布·鲍威尔、施蒂纳的哲学立场
- 用户涉及"真正的社会主义"批判或意识形态变形分析
- 左翼理论星图项目中的哲学基础模块

## 使用方法

1. 在需要分析社会结构、意识形态或历史变革时，查询 `knowledge-base.json` 中的相关条目
2. 对于需要深入分析的论题，参考 `references/deep/` 中的专题文档
3. 使用 `overview.json` 快速定位概念所在的章节位置
4. 与其他左翼理论星图组件（如西方马克思主义、资本论、帕舒卡尼斯等）交叉参考
